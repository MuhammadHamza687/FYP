ℹ️ What is Buyer-Side Verification?

When you list a product via the seller API, it doesn't always confirm the product is visible to customers. This verification step calls the buyer/storefront API — the same endpoint a real customer's browser would call — to confirm the listing is actually findable. This is a critical QA step that s2.py was missing.
